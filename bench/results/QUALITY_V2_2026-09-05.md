# Scoring v2.0 quality-gated A/B — 2026-09-05

**Decision: do not promote the faster candidate.** The 32ms capture + fragmented presynthesis
candidate improved clean latency but failed hesitation reply fidelity. Runtime source has been
restored to the pre-optimization worktree, retaining the earlier reviewed cancellation fix.
Scoring v2 remains installed. No commit, publication, frontend dependency bump or deployment.

## Experiment

Real Deepgram Flux + ElevenLabs flash, fixed mock LLM and byte-identical person audio. Five
conversations per arm per scenario: **30 conversations / 180 person turns / 40 scripted
interruptions total**, collected 22:08–22:42 UTC. Arms interleaved B P P B B P P B B P within each
scenario. Baseline includes the earlier cancellation fix; candidate adds only transport/preroll/
bootstrap changes and bounded first-word presynthesis lookahead. No endpoint, echo, interruption,
model or prompt threshold was loosened.

Scoring version **2.0 on both arms**, recomputed after collection using the final scorer. All 180
reply windows transcribed using the same local faster-whisper `small.en`, CPU int8, beam 5,
English, no reference prompt, no previous-text conditioning. CPU transcription ran after the audio
rig was stopped and defaults restored. OpenAI keys returned HTTP 429; no OpenAI-produced
transcripts enter this comparison. Transcriber package/config provenance is in each cached result
and pooled JSON. Transcription is an estimate, not a human semantic assessment.

### What failed

In candidate hesitation runs **1 and 5**, the script's turn 4 was split into two STT finals:

1. `Send the confirmation to my email.` — committed before the scripted continuation.
2. `Actually, make that a text message.` — committed as another turn after the user resumed.

The agent began a reply and correctly stopped when the person continued. However, the fixed mock
selects a response by counting user messages: the extra final advanced it one turn too far.
Recorded speech for turn 4 became the parking answer, and turn 5 became **“I have nothing scripted
for this turn.”** Both utterances are confirmed in the local transcripts and timelines; they are
not merely ASR punctuation errors. This created four off-script scored replies.

The measurement exposes an interaction with the mock's turn counter, not proof that a real LLM
would utter that same wrong answer. But the premature turn split is real, can trigger premature
production actions, and fails this benchmark's response contract. We did not remap the script,
exclude these runs, or relax the accuracy gate to claim the 26.3% clean latency improvement.
A repeated test would be needed to establish frequency; 2/5 is a small sample.

The baseline hesitation coverage below 100% largely reflects the transcriber rendering spoken
numbers as `4` and `7` vs script `four` and `seven`. Scoring does not selectively normalize these
for one arm. This small systematic ASR representation issue is distinct from the candidate's
parking/fallback substitutions.

- Hesitation baseline: 1281, 1632, 1428, 1516, 1448. Candidate: 1328, 1414, 2217, 1239, 1239.

Pooled upper medians and nearest-rank p95 follow the historical timing convention. These are five
clustered conversations per arm, not 30 independent experiments. No significance claim. Candidate
hesitation p95 regressed and stall counts increased in all three scenarios. It is not an across-
the-board performance win even apart from the failed fidelity gate.

## Scoring update

See [SCORING_V2.md](../SCORING_V2.md) for definitions and caveats.

- Sustained stops use the last overlapping audio segment and require at least 200ms silence before
  person_end. Sentence gaps followed by speech cannot win the score.
- Delivery comes from recorded audio transcripts, never the SUT's UI/history `heardNw`.
- No attributable audio is failure; missing transcription is unknown, not success.
- Input WER does not search for the transcript that best matches the answer key. Explicit IDs or
  conservative callback ownership are used; ambiguous turns are visible.
- Whole-conversation WER retains all finals without turn attribution, so ambiguity cannot hide
  missed/extra/echo words. This is the primary input accuracy check here.
- Per-turn STT ambiguity rose with shorter reply cycles: clean 2/30→16/30; echo 0/30→6/30. Per-turn
  WER alone would not be a fair gate. Whole-conversation input WER remained exactly equal.
- Noise heuristics and echo lexical diagnostics are retained and labeled as proxies; generic
  “zero false interruptions” and echo causation are not inferred from lack of instrumented events.
- Old results remain explicitly **v1**. No mixed-version ranking or competitor rerun claimed.

## Next experiment

Separate capture and presynthesis in an ablation, add regression scenarios for resumed-user
turn merging, and treat premature action authorization as a correctness condition. Do not merely
make the mock forgive our split while competitors still pay for theirs. Keep the v2 quality gate;
the clean latency gain is worth pursuing, but not at the measured fidelity cost.
